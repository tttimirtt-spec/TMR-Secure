# TMR-Secure website

## Публикация

Сайт автоматически публикуется на GitHub Pages при каждом обновлении ветки `main`.
Адрес: `https://tttimirtt-spec.github.io/TMR-Secure/`.

Если Pages ещё не включён в настройках репозитория, откройте **Settings → Pages**
и выберите **GitHub Actions** в разделе **Build and deployment**.

В репозитории также находился ключ доступа к Tabrica API прямо в HTML. Ключ удалён из клиентского кода: перед публикацией отзовите его в Tabrica и создайте новый. Для безопасной работы счётчика и отзывов нужен серверный API-прокси; ключ нельзя возвращать в HTML или JavaScript.
